# azure-devops-attachment-mcp-server

An [MCP](https://modelcontextprotocol.io) server (stdio) for managing **work item attachments** on
**on-premise Azure DevOps Server** (2019/2020/2022, TFS) over the REST API with a Personal Access Token.
It exposes four tools: list, add, delete and download attachments of a work item.

> Work in progress. Documentation will be completed as the implementation lands.
